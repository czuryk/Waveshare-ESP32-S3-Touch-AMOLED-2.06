# Collection if stuff for Waveshare ESP32 S3 Touch AMOLED 2.06

The SmartWatch: https://www.waveshare.com/wiki/ESP32-S3-Touch-AMOLED-2.06

- ### soundrecorder - A test sketch that checks the built-in microphone of the watch. It records audio for 30 seconds using the audio chip es8311 and es7210 microphone chip then saves it as a WAV file to the SD card.
